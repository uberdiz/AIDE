# Extend AIDE with AIDE

- **AIDE: New Extension** scaffolds a command, panel, sidebar view, status bar item, AI tool, agent, theme or MCP server.
- **AIDE: Build Extension with AI** describes an extension and lets the Extension Builder agent write, check and document it.
- **AIDE: Run Extension in Development Host** runs it immediately. **Install Extension from Folder** packages it as a VSIX and installs it.
- Extensions can register tools, agents, providers, connectors and workflows through the AIDE API (see **AIDE: Open Extension API Docs**).
- Add MCP servers under **AIDE → MCP Servers** to give agents new tools without writing code.
